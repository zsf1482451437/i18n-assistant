# i18n-assistant

## 多语言一键写入工具

### 背景

项目支持 9 种语言，传统方式下添加一条翻译需要在 9 个不同的命名空间（文件）中分别修改，操作繁琐且容易出错；
当然，n 种同理

### 解决方案

整合以下工具实现自动化翻译写入：

- [i18nexus 平台](https://app.i18nexus.com)
- 谷歌浏览器插件
- 本地 Node 服务

### 实现步骤

1. 在[i18nexus 平台](https://app.i18nexus.com)上添加需要翻译的内容
2. 使用谷歌浏览器插件提取翻译信息
3. 启动本地 Node 服务，在服务返回的页面中：
   - 刷新翻译数据
   - 提供多语言本地路径（例如：`D:\workspace\ttmall_next\public\locales`）
   - 选择目标命名空间
   - 点击应用翻译

完成以上步骤后，9 种语言的翻译将自动写入对应文件，一键完成，高效便捷。
